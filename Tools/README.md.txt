# Tools
Python Based StandAlone Mac Apps for Image Batch Manipulation.

INSTAPAD : Adds padding to fit Instagram's multiple compatible formats

STAMPREMARKER : Find the Old Stamp on Image and Try to Batch OverLay

PNG2JPEG : Batch convert folder of PNG to JPEG

JimAndIArtBrowser_Chrome_Ext : Chrome Extension to Browse Gemini Search History and Download Images and Videos
